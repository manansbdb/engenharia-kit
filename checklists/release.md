# Checklist — release

- [ ] Changelog / notas de release escritas
- [ ] Versão bumpada (semver)
- [ ] CI verde na branch de release
- [ ] Migrações testadas (up + down ou plano de rollback)
- [ ] Feature flags / config de produção revistas
- [ ] Monitorização / alertas prontos para o que muda
- [ ] Comunicação à equipa (Slack / Notion / canal)
- [ ] Plano de rollback documentado em 3 passos
